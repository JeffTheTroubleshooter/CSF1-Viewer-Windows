# CSF1 Viewer — Windows

Public host tool for [JCkernel](https://github.com/JeffTheTroubleshooter/JCkernel) CSF1 disks.

Sister editions:

- [CSF1-Viewer-Linux](https://github.com/JeffTheTroubleshooter/CSF1-Viewer-Linux)
- [CSF1-Viewer-macOS](https://github.com/JeffTheTroubleshooter/CSF1-Viewer-macOS)

## Run

Install Python 3 with tcl/tk. Double-click `CSF1-Viewer.bat`.

**Update** reads this public repo. No GitHub login.
